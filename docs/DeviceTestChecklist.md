## 通用测试步骤（所有平台）

1. **启动**：从桌面/命令行启动导出产物，确认标题画面正常显示（标题文字、菜单按钮、背景图/BGM）
2. **新游戏**：点击"新游戏"或"New Game"，进入第 1 章
3. **ch1 完整播放**：点击推进对话，确认无崩溃、画面/文字/音频正常
4. **ch2 冲突场景**：推进至第 2 章，确认立绘切换、BGM 变更正常
5. **ch3 分支选择**：在第 3 章，确认出现玩家选择分支（throw_away / use_poison）
6. **选择分支**：点击一个选项，确认剧情正确分支
7. **ch4 结局**：推进至第 4 章结局，确认结局达成提示
8. **存档**：在任意对话处打开存档面板 → 存档 → 确认缩略图生成
9. **读档**：返回标题 → 读取存档 → 确认恢复到正确位置
10. **设置**：打开设置面板 → 修改文字速度/音量 → 确认生效
11. **退出**：退出游戏 → 确认进程正常结束无残留

## 平台特定测试

### Windows

- [ ] 启动 exe（export产物）
- [ ] 窗口模式正常大小（1280×720）
- [ ] 全屏模式（Alt+Enter）无变形
- [ ] 10 分钟连续播放无崩溃/内存泄漏
- [ ] 最小化/恢复窗口后继续正常工作
- [ ] Alt+F4 / 关闭窗口正常退出

### Linux

- [ ] 启动二进制文件（export产物）
- [ ] X11/Wayland 兼容（检查日志无显示异常）
- [ ] 窗口管理（拖动/调整大小/最大化）
- [ ] 10 分钟连续播放无崩溃
- [ ] Ctrl+Q 正常退出

### Android

- [ ] APK 安装成功
- [ ] 启动 → 横屏模式自动适配
- [ ] 触控操作：点击推进对话、点击选项分支
- [ ] 长按右键菜单正常
- [ ] 设置面板可滑动/可操作
- [ ] 存档/读档面板触控正常
- [ ] 退后台 → 回到前台 → 游戏继续（测试 3 次）
- [ ] 5 分钟连续播放无崩溃
- [ ] 返回键 → 确认退出对话框
